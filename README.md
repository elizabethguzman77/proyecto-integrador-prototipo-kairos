# proyecto-integrador-prototipo-kairos
Prototipo académico de Kairós, un producto informático orientado a fortalecer la prevención de riesgos digitales en estudiantes extranjeros durante su adaptación a Ecuador. Integra psicología cognitiva, factores culturales y diseño centrado en el usuario para promover decisiones seguras y deliberadas ante posibles fraudes y estafas.
